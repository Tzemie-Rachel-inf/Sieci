1. PYTANIE: Lista interfejsów sieciowych w systemie (format: nazwa-status).
   POLECENIE: ip addr
   ODPOWIEDŹ:
   lo       UNKNOWN
   enp0s25  DOWN
   wlan0    UP

--------------------------------------------------------------------------------
2. PYTANIE: Adres MAC routera, który łączy sieć pracowni z internetem.
   POLECENIE: ip route (aby poznać IP bramy) -> ip neigh (aby poznać MAC)
   ODPOWIEDŹ:
   6c:3b:6b:fe:c0:d1

--------------------------------------------------------------------------------
3. PYTANIE: Zmiana adresu MAC karty sieciowej Ethernet na inną wartość.
   POLECENIE: 
   ip link set dev enp0s25 address xx:xx:xx:xx:xx:xx

--------------------------------------------------------------------------------
4. PYTANIE: Ping wszystkich urządzeń jednocześnie w podsieci pracowni.
   POLECENIE: ip addr (aby poznać adres rozgłoszeniowy), a następnie:
   ping -b 192.168.88.255
